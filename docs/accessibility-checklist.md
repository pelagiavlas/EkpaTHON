# Έλεγχος προσβασιμότητας

## Τι ελέγχεται αυτόματα

`npm run a11y` (στον φάκελο `frontend`, με τον backend να τρέχει και δεδομένα demo):

- axe-core σε **22 οθόνες της ροής του demo** × κινητό/laptop × κανονικά/έντονα χρώματα = 88 έλεγχοι.
  Περιλαμβάνει ανέβασμα PDF, μελέτη, υποδείξεις, απάντηση, πρόοδο, ρυθμίσεις και σελίδα υποστηρικτή.
- Κανόνες: WCAG 2.0/2.1/2.2 A και AA, οι κανόνες AAA που ξέρει ο axe (π.χ. αντίθεση 7:1) και best practices.
- Τελευταίο αποτέλεσμα: **0 προβλήματα**.
- Τα χρώματα κειμένου ελέγχθηκαν και με υπολογισμό: όλα ≥ 7:1 και στα δύο θέματα.

Ο axe βρίσκει περίπου το 30–40% των προβλημάτων. Τα υπόλοιπα θέλουν άνθρωπο.

## Τι πρέπει να ελέγξουμε με το χέρι

### Πληκτρολόγιο (χωρίς ποντίκι)
- [ ] Tab σε όλη τη ροή: μαθήματα → ανέβασμα PDF → επίπεδο → ενότητα → ερωτήσεις → υποδείξεις → απάντηση → πρόοδος.
- [ ] Το πρώτο Tab δείχνει το «Πήγαινε στο κύριο περιεχόμενο».
- [ ] Το πλαίσιο focus φαίνεται πάντα και δεν κρύβεται κάτω από την πάνω μπάρα ή το κάτω μενού (WCAG 2.4.11).
- [ ] Το «Διάλεξε PDF» ανοίγει με Enter ή Space.
- [ ] Τα κουμπιά επιλογών (radio) αλλάζουν με τα βελάκια.

### Αναγνώστες οθόνης
- [ ] **NVDA + Firefox/Chrome** (Windows): σε κάθε νέα οθόνη διαβάζεται πρώτα ο τίτλος.
- [ ] NVDA: οι υποδείξεις διαβάζονται μόλις εμφανιστούν (aria-live), χωρίς να μετακινηθεί το focus.
- [ ] NVDA: μετά την απάντηση διαβάζεται το μήνυμα («Σωστά. Το βρήκες.» ή «Ας το δούμε μαζί»).
- [ ] **VoiceOver + Safari** (iPhone): όλη η ροή με swipe.
- [ ] **TalkBack + Chrome** (Android): όλη η ροή.
- [ ] Οι όροι με την εξήγηση δίπλα διαβάζονται κατανοητά.
- [ ] Οι τύποι (x̄ ± z · σ / √n): ακούγεται κάτι λογικό; Μετά ακολουθεί η εξήγηση κάθε συμβόλου.
- [ ] Αν η ανάγνωση φωναχτά της εφαρμογής μπερδεύεται με τον αναγνώστη οθόνης: «Ρυθμίσεις → Ανάγνωση φωναχτά → Να διαβάζει μόνο του: Όχι».

### Εμφάνιση
- [ ] Zoom 200% και 400% στον browser: κανένα κείμενο δεν κόβεται και δεν χρειάζεται οριζόντιο scroll.
- [ ] «Τεράστια» γράμματα και «Πολύς» χώρος γραμμών: όλα χωράνε.
- [ ] Windows High Contrast / Forced colors: τα κουμπιά και το focus φαίνονται.
- [ ] Οι εικόνες είναι καθαρές και στο θέμα με τα έντονα χρώματα.

### Φωνή
- [ ] Υπάρχει ελληνική φωνή στη συσκευή του demo (Ρυθμίσεις → Ανάγνωση φωναχτά → «Δοκίμασε τη φωνή»).
- [ ] Το «Σταμάτα» σταματά αμέσως την ανάγνωση.
- [ ] Η επισήμανση του κομματιού που διαβάζεται ακολουθεί τη φωνή.

### Γλώσσα και περιεχόμενο (με ανθρώπους, ιδανικά με φοιτητές της Μονάδας Προσβασιμότητας)
- [ ] Το κείμενο «Εύκολο στην Ανάγνωση» του demo το ελέγχει κάποιος με εμπειρία στο Easy-to-Read.
- [ ] Τα μηνύματα δεν ακούγονται παιδικά ή επικριτικά.
- [ ] Η υπόδειξη 4 δεν δίνει την απάντηση σε καμία ερώτηση.
- [ ] Οι λέξεις στο UI είναι γνωστές σε όλους («Υποδείξεις», «Επίπεδο βοήθειας», «Πρωτότυπο»).
