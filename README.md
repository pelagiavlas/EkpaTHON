# Study Buddy — ΕΚΠΑthon 2026

Εφαρμογή που βοηθά φοιτητές με γνωστικές και μαθησιακές δυσκολίες (νοητική αναπηρία, ADHD, δυσλεξία, αυτισμό) να οργανώσουν τη μελέτη τους σε μικρά κομμάτια, με πρόβλεψη του πραγματικού χρόνου που χρειάζονται.

## Εκτέλεση

### Backend (Python 3.12)

```powershell
cd backend
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m uvicorn app.main:app --reload
```

- API και δοκιμές από τον browser: http://localhost:8000/docs
- Tests: `.venv\Scripts\python -m pytest`

## Τι πήραμε από το StudyBuddy και τι είναι καινούργιο

Βάση: το δικό μας προηγούμενο project [StudyBuddyApp](https://github.com/pelagiavlas/StudyBuddyApp) (Java/JavaFX). Δεν αντιγράψαμε κώδικα. Ξαναγράψαμε σε Python μόνο την **ιδέα** του αλγορίθμου προγραμματισμού.

| Από το StudyBuddy (ιδέα) | Τι αλλάξαμε / τι είναι νέο |
|---|---|
| Εργασίες ανά είδος: διάβασμα, επανάληψη, εργασία (`Task.java`) | Η διάρκεια δεν είναι πια σταθερή (2 ώρες). Βγαίνει από την εκτίμηση × προσωπικό πολλαπλασιαστή και σπάει σε κομμάτια 15–45 λεπτών (προεπιλογή 30) |
| Εκτίμηση από σελίδες × δυσκολία / ταχύτητα ανάγνωσης (`CalculativeAlgorithm.java`) | Η ταχύτητα ανάγνωσης είναι προσωπική ρύθμιση, όχι ίδια για όλους |
| Διαθεσιμότητα σε ώρες ανά μέρα + μέρες εκτός (`Availability.java`) | Χρονικά διαστήματα ανά μέρα (π.χ. Δευ 17:00–20:00), οπότε κάθε κομμάτι έχει πραγματική ώρα και διαλείμματα |
| 50 τυχαία έγκυρα προγράμματα, κρατάμε το καλύτερο (`SimulateAnnealing.java`, `TaskAssignment.java`) | Ίδια ιδέα, με τίμιο όνομα («best-of-N»). Η επιλογή δίνει προτεραιότητα στις κοντινές προθεσμίες και κάθε πρόγραμμα αναπαράγεται με seed |
| Βαθμολογία: ποινή για ίδιο μάθημα ίδια μέρα και σε συνεχόμενες μέρες (`Scoring.java`) | Νέες ποινές: πάνω από 3 συνεχόμενα κομμάτια χωρίς διάλειμμα, κομμάτια που δεν χωράνε πριν την προθεσμία, στρίμωγμα την τελευταία μέρα |
| Επαναλήψεις μετά από 1, 7, 16, 35 μέρες και μετά διπλασιασμός (`Repetition.java`) | Κρατήθηκε όπως ήταν |
| Ώρα έναρξης και ολοκλήρωσης (`ScheduledTask.java`) | Κρατάμε πλήρη ημερομηνία-ώρα, πραγματικά λεπτά και αιτήματα βοήθειας ανά κομμάτι. Αυτά τροφοδοτούν το μοντέλο πρόβλεψης |

Σφάλματα της Java έκδοσης που διορθώθηκαν: το `0` σήμαινε «κενή θέση» αλλά ήταν και ο δείκτης της πρώτης εργασίας, που έτσι δεν έμπαινε ποτέ στο πρόγραμμα. Επίσης όλη η κατάσταση ήταν σε καθολικές (`static`) μεταβλητές.

**Εντελώς νέα:** μοντέλο πρόβλεψης χρόνου, κίνδυνος προθεσμίας, σύνδεση με LLM (σπάσιμο σε βήματα, «Εύκολο στην Ανάγνωση»), σταδιακή μείωση βοήθειας, προσβάσιμο PWA.
