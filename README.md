# Study Buddy: ΕΚΠΑthon 2026

> **«Μετράμε πόσο λιγότερο μας χρειάζεσαι.»**

Εφαρμογή μελέτης για φοιτητές με νοητική αναπηρία και μαθησιακές δυσκολίες.

Ο φοιτητής ανεβάζει το PDF του μαθήματος και το βλέπει και το ακούει σε **«Εύκολο στην Ανάγνωση»**. Μετά απαντά σε ερωτήσεις κατανόησης. Όταν κολλάει, παίρνει **υποδείξεις** που δεν δίνουν ποτέ έτοιμη την απάντηση: στα πρώτα επίπεδα εξηγούν, στα επόμενα τον στέλνουν να ψάξει στο πρωτότυπο κείμενο. Κάθε **ενότητα** έχει δικό της επίπεδο βοήθειας, που ξεκινά πάντα από την πλήρη βοήθεια. Όσο τα καταφέρνει μόνος, η εφαρμογή **προτείνει λιγότερη βοήθεια** και αποφασίζει ο ίδιος.

Είναι εργαλείο μελέτης και αυτονομίας: όχι θεραπεία, όχι εργαλείο αξιολόγησης για το πανεπιστήμιο. Όλα τα δεδομένα μένουν στη συσκευή του φοιτητή. Δεν αποθηκεύεται διάγνωση.

## Γρήγορη εκκίνηση (για το demo)

Χρειάζεστε Python 3.12 και Node.js 20 ή νεότερο. Σε PowerShell:

```powershell
# 1. Backend
cd backend
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt

# 2. Frontend (μία φορά, και ξανά μετά από κάθε αλλαγή στο frontend)
cd ..\frontend
npm install
npm run build

# 3. Δεδομένα demo: ΣΒΗΝΕΙ ό,τι υπάρχει και βάζει 2 εβδομάδες προσομοιωμένης χρήσης
cd ..\backend
.venv\Scripts\python -m scripts.seed_demo --reset

# 4. Εκκίνηση
.venv\Scripts\python run.py
```

Ανοίξτε το **http://localhost:8000**. Το PDF για το ζωντανό ανέβασμα είναι στο `backend\demo\kefalaio-3-diastima-empistosynis.pdf`.

- Το `run.py` τρέχει πάντα μέσα από τον φάκελο `backend`. Αν τρέξετε απευθείας το `app\main.py`, βγαίνει το σφάλμα `No module named 'app'`.
- **Παλιά βάση από προηγούμενη έκδοση:** τρέξτε το βήμα 3 (`--reset`), γιατί οι πίνακες άλλαξαν.
- **Από κινητό στο ίδιο Wi-Fi:** βάλτε `STUDYBUDDY_HOST=0.0.0.0` στο `backend\.env` και ανοίξτε `http://<IP-του-laptop>:8000`. Η εγκατάσταση ως εφαρμογή (PWA) θέλει HTTPS. Σε localhost δουλεύει και χωρίς.

### Για ανάπτυξη (αλλαγές στο frontend χωρίς build)

```powershell
cd backend;  .venv\Scripts\python run.py        # API στο :8000
cd frontend; npm run dev                         # εφαρμογή στο http://localhost:5173
```

## Σενάριο demo (3 λεπτά)

1. **Τα μαθήματά μου:** δύο μαθήματα, χωρίς καμία ερώτηση ή τεστ πριν την πρώτη χρήση.
2. **Στατιστική → Ανέβασε PDF** → διαλέξτε το demo PDF → «Ανέβασε». Πάτε **κατευθείαν στις ενότητες**. Όλες είναι στο επίπεδο 1. Οι 3.1 και 3.2 δείχνουν «Έχεις πρόταση», γιατί το ίδιο θέμα έχει ήδη διαβαστεί (προσομοιωμένο ιστορικό).
3. **Ενότητα 3.4 (επίπεδο 1):** Εύκολο κείμενο σε μικρά κομμάτια, με εικόνα και παράδειγμα. Πατήστε «Άκου». Δείξτε το «Πρωτότυπο» με ένα πάτημα.
4. **Προεπισκόπηση:** στην ίδια σελίδα, «Προεπισκόπηση για την παρουσίαση» → «Επίπεδο 3». Η ίδια ενότητα ξεκινά τώρα από το πρωτότυπο. Γυρίστε στο «Επίπεδο 1». Το πραγματικό επίπεδο δεν αλλάζει.
5. **Ερωτήσεις 3.4:** **Βοήθεια** (θύμηση του παραδείγματος) → **Βοήθεια** («Με 100 φίλους ξέρεις πιο σίγουρα;») → «Το διάστημα μικραίνει» → «Σωστά. Το βρήκες.»
6. **Ενότητα 3.2:** η πρόταση «Έχεις ξαναδιαβάσει αυτό το θέμα. Θες να ξεκινήσεις με λιγότερη βοήθεια;» λέει τι θα αλλάξει → «Ναι». Τώρα ανοίγει πρώτα το πρωτότυπο.
7. **Ερωτήσεις 3.2 (επίπεδο 3):** **Βοήθεια** ×3: «Η απάντηση είναι στην ενότητα 3.2», «Είναι στην 1η παράγραφο» (επισημαίνεται), «Βρες την πρόταση που λέει τι είναι το διάστημα εμπιστοσύνης». Πατήστε τη 2η πρόταση («Δεν είναι αυτή»), μετά την 1η («Τη βρήκες»). Γράψτε «εύρος τιμών» → «Σωστά». Εμφανίζονται ήρεμα ορόσημα.
8. **Πρόοδος:** «Προσομοιωμένα δεδομένα», η βοήθεια που πέφτει, το επίπεδο κάθε ενότητας, οι αλλαγές επιπέδου και τα ορόσημα.

### Τα 4 επίπεδα υποστήριξης (ανά ενότητα)

Κάθε νέα ενότητα ξεκινά στο **επίπεδο 1**, χωρίς τεστ ή κατηγοριοποίηση. Τα επίπεδα αλλάζουν **μόνο την υποστήριξη μάθησης**. Οι ρυθμίσεις προσβασιμότητας (γράμματα, διάστιχο, αντίθεση, ανάγνωση φωναχτά, κίνηση) **δεν αλλάζουν ποτέ** με το επίπεδο.

| Επίπεδο | Κείμενο | Όροι | Ερωτήσεις | Υποδείξεις |
|---|---|---|---|---|
| 1. Πλήρης βοήθεια | Εύκολο, μικρά κομμάτια, εικόνα και παράδειγμα σε κάθε έννοια | Εξήγηση μέσα στο κείμενο | 2 επιλογές με εικόνες | Εξηγούν |
| 2. Καθοδηγούμενη | Εύκολο, μεγαλύτερα κομμάτια, εικόνες μόνο στα δύσκολα | Εξήγηση με πάτημα | 3 επιλογές | Εξηγούν |
| 3. Ψάχνω στο κείμενο | Πρώτα το πρωτότυπο, το Εύκολο πίσω από κουμπί | Γλωσσάρι κατ' επιλογή | Ανοιχτές | «Ψάξε στο κείμενο» |
| 4. Αυτονομία | Πρωτότυπο χωρίς προσθήκες | Όχι | Βασικά σημεία, δική ερώτηση, εξάσκηση | Μόνο αν τη ζητήσει |

Το κουμπί «Εύκολο κείμενο» υπάρχει σε **όλα** τα επίπεδα, στην ίδια θέση.

**Κανόνες** (`backend/config.toml`, ανά ενότητα, μόνο **προτάσεις**):
- 3 επιτυχίες στη σειρά → πρόταση για λιγότερη βοήθεια. Στα επίπεδα 1–2, επιτυχία = σωστή με την πρώτη και 0–1 υποδείξεις. Στα 3–4 = σωστή χωρίς επιστροφή στις εξηγήσεις. Το ψάξιμο στο κείμενο δεν μετράει ως δυσκολία.
- 2 από τις 3 τελευταίες δύσκολες → πρόταση για περισσότερη βοήθεια.
- Στα επίπεδα 3–4: Εύκολο κείμενο σε 2 από τις 3 τελευταίες φορές → πρόταση για ένα επίπεδο πίσω.
- Ίδιο θέμα (ίδιος τίτλος ενότητας στο ίδιο μάθημα) → πρόταση για το επίπεδο που είχε φτάσει εκεί.
- Κάθε πρόταση λέει τι θα αλλάξει. **Τίποτα δεν αλλάζει χωρίς «Ναι».** Με «Όχι τώρα» η μέτρηση ξεκινά από την αρχή.

**Ορόσημα** (μία φορά το καθένα, ήρεμο μήνυμα, χωρίς animation): πρώτη ενότητα από το πρωτότυπο, πρώτη σωστή χωρίς βοήθεια, πρώτη πρόταση που βρήκε στο κείμενο, πρώτη ενότητα στο επίπεδο 3 και στο 4, πρώτη εξάσκηση.

**Εξάσκηση σαν στις εξετάσεις** (επίπεδο 4): χωρίς βοήθεια, **χωρίς χρονόμετρο** εκτός αν το ζητήσει ο φοιτητής (μπορεί να το παγώσει και δεν κόβει την εξάσκηση), και δεν αλλάζει το επίπεδο.

### Οι υποδείξεις
**Επίπεδα 1–2 (εξηγούν):**
1. Πού να κοιτάξεις, με κουμπί που ανοίγει την ενότητα ή ξαναπαίζει το παράδειγμα.
2. Μια καθοδηγητική ερώτηση.
3. Δύο επιλογές.
4. Η ίδια έννοια με **άλλο** καθημερινό παράδειγμα. Ποτέ η απάντηση.

**Επίπεδα 3–4 (ψάξε μόνος σου, μόνο στο πρωτότυπο):**
- α) «Η απάντηση είναι στην ενότητα 3.4. Διάβασέ την ξανά.»
- β) «Είναι στη 2η παράγραφο.» Η παράγραφος επισημαίνεται με πλαίσιο και τη λέξη «Εδώ».
- γ) «Βρες την πρόταση που λέει … Πάτησέ την.» Κάθε πρόταση είναι κουμπί. Ο έλεγχος γίνεται στον server.
- δ) Μετά από 3 λάθος προτάσεις, ή αν ζητήσει ξανά βοήθεια, επιστρέφουν οι υποδείξεις του επιπέδου 2. Αυτό καταγράφεται για το fading.

Η πρόταση-στόχος βρίσκεται αυτόματα από τις κοινές λέξεις με το `key_point` και το `accept`. Στο demo, η αυτόματη επιλογή συμφωνεί με τη χειροκίνητη σε 7 από τις 8 ερωτήσεις. Στα fixtures μπορείτε να την ορίσετε με το χέρι (`source_sentence`, `source_hint`).

Η σωστή απάντηση, η εξήγηση και η πρόταση-στόχος **μένουν στον server**. Η εξήγηση φαίνεται μόνο αφού ο φοιτητής δοκιμάσει.

## Σύνδεση με LLM αργότερα

Σήμερα **δεν γίνεται καμία κλήση στο internet και δεν υπάρχει API key**. Όλο το περιεχόμενο περνά από το interface `ContentProvider`.

1. Συμπληρώστε τις τρεις μεθόδους στο **`backend/app/content/llm.py`**. Μέσα στο αρχείο υπάρχουν σχόλια για το τι στέλνουμε, πώς ελέγχουμε την απάντηση με Pydantic και τι γίνεται αν είναι άκυρη (μία επανάληψη, μετά σφάλμα).
2. Αντιγράψτε το `backend/.env.example` σε **`backend/.env`** και βάλτε:
   ```
   CONTENT_PROVIDER=llm
   ANTHROPIC_API_KEY=...
   ```
   Το `.env` δεν ανεβαίνει στο git. Το κλειδί μένει μόνο στον backend.
3. Στο LLM πηγαίνει **μόνο το κείμενο της ύλης** και γενικές παράμετροι (επίπεδο, «Εύκολο στην Ανάγνωση»). Ποτέ όνομα, ρυθμίσεις ή διάγνωση.

Χωρίς `CONTENT_PROVIDER` (ή με `mock`) η εφαρμογή δουλεύει όπως τώρα.

**Νέο έτοιμο περιεχόμενο χωρίς LLM:** προσθέστε ένα JSON στο `backend/app/content/data/fixtures/`, με τη μορφή του `statistics_ch3.json`. Οι τίτλοι των ενοτήτων πρέπει να είναι ίδιοι με αυτούς του PDF.

Ελέγχει επίσης ότι γράμματα, διάστιχο, αντίθεση και κίνηση είναι **ίδια στα επίπεδα 1–4**. **Μετά το `npm run a11y`:** ο έλεγχος απαντά σε ερωτήσεις, οπότε τρέξτε ξανά το `seed_demo --reset` πριν από την παρουσίαση.

## Προσβασιμότητα

- WCAG 2.2 AA, και από το AAA: αντίθεση κειμένου ≥ 7:1, κανένα χρονικό όριο, εξήγηση δύσκολων λέξεων, κουμπιά ≥ 44×44 px.
- W3C COGA: μία ενέργεια ανά οθόνη, «Πίσω» και «Άκου» πάντα στην ίδια θέση, λίγες επιλογές (2–3), κανένα αρνητικό μήνυμα, επιβεβαίωση πριν από σβήσιμο.
- Κάθε πληροφορία με δύο τρόπους (κείμενο + εικονίδιο/εικόνα/ήχος).
- Ρυθμίσεις ως JSON, που εφαρμόζονται με μεταβλητές CSS στο `<html>`. Οι αρχικές τιμές έρχονται από τα `prefers-reduced-motion` και `prefers-contrast`.
- Καμία ερώτηση ή αξιολόγηση πριν την πρώτη χρήση. Μόνο ένα μήνυμα: «Μπορείς να αλλάξεις γράμματα, χρώματα και ήχο στις Ρυθμίσεις».
- Σελίδα «Δήλωση προσβασιμότητας» μέσα στην εφαρμογή (Ρυθμίσεις).

## Τι δεν κάνει ακόμα

- Σκαναρισμένα PDF (χωρίς OCR): εμφανίζεται το μήνυμα «Αυτό το PDF είναι φωτογραφία, δοκίμασε άλλο».
- Η απλοποίηση με κανόνες (PDF χωρίς fixture) είναι απλή. Γι' αυτό η εφαρμογή το λέει και δείχνει πάντα το πρωτότυπο.
- Οι ανοιχτές απαντήσεις ελέγχονται με λέξεις-κλειδιά. Αν δεν ταιριάξουν, ο φοιτητής συγκρίνει μόνος του με το «τι περιμέναμε».
- Ο σύνδεσμος του υποστηρικτή δουλεύει μόνο όσο τρέχει η εφαρμογή και είναι προσβάσιμη στο δίκτυο.
- Δεν έχει γίνει ακόμα δοκιμή με φοιτητές.
